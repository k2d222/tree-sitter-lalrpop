# tree-sitter-lalrpop

LLM-generated [LALRPOP](https://github.com/lalrpop/lalrpop/) grammar for [tree-sitter](https://github.com/tree-sitter/tree-sitter).

It was generated from the [bootstrapped LALRPOP grammar](https://github.com/lalrpop/lalrpop/blob/master/lalrpop/src/parser/lrgrammar.lalrpop).
It supports Rust code injections and has syntax highlighting queries. Tested with the [Helix editor](https://github.com/helix-editor/helix).
